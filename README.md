# Evaluación de Pitch · jueces

Solo para jueces: entran con su nombre (sin contraseña) y califican a cada alumno que presenta de manera individual. Ocho rubros con barras de puntos enteros, de 0 al máximo de cada uno (total 100). La calificación de cada alumno es el promedio de los jueces que enviaron.

- `index.html`: la página (GitHub Pages). No guarda nombres de alumnos: llegan del servidor al entrar.
- `Code.gs`: el script de Google que guarda las respuestas en una hoja privada. La lista de alumnos y la contraseña del profe solo viven en el editor de Apps Script.
